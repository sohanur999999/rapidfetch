Questions

Before you install

Is RapidFetch really free, or is there a Pro upgrade?

It is free for life. There is no paid tier, trial, subscription, registration key or account. Every core feature on this page is included in the free build. If that ever changes, this page and the listing will say so before anything is paywalled.

Does the Chrome extension work without the desktop app?

No. The extension is a companion: it captures downloads and media from Chrome and hands them to the RapidFetch desktop app on the same PC. Install the Windows app first, then the extension.

Which browsers are supported?

Chrome, Microsoft Edge, Brave, Vivaldi, Opera and other Chromium browsers with Manifest V3 support. The desktop app is for Windows 10 and 11, 64-bit.

Can it download YouTube, Facebook or other videos?

RapidFetch detects direct video, audio and HLS streams and can resolve supported pages through the optional yt-dlp engine, including Facebook reels and watch pages. Only download content you own or have permission to save, and respect each site’s terms.

Does RapidFetch collect my data?

No. There is no analytics, telemetry, advertising SDK or user account. Download history and settings stay in %APPDATA%\RapidFetch, and the extension only communicates with the desktop app on your computer. Read the privacy policy.

Why does the extension ask for access to all sites?

Downloadable media can be served from any domain, so the extension has to inspect the page and media responses on sites you visit to find download options. It does not inject ads, modify page content, or change your search engine or new-tab page.
