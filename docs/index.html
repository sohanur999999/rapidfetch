Install it in about a minute

This is the same extension package prepared for the Web Store. Chrome loads it from the extracted folder, so keep that folder in a permanent location.

Download extension ZIP
  1. Install the Windows app first. Setup registers the native messaging host that connects Chrome to RapidFetch.
  2. Extract the ZIP to a permanent folder. It must contain manifest.json at the top level; do not select the ZIP itself.
  3. Open chrome://extensions, enable Developer mode, click Load unpacked, and select the extracted folder.
  4. Pin RapidFetch to the toolbar and test a download link. A developer-mode reminder is normal for manual installs.

Questions

Before you install

Is RapidFetch really free, or is there a Pro upgrade?

It is free for life. There is no paid tier, trial, subscription, registration key or account. Every core feature on this page is included in the free build. If that ever changes, this page and the listing will say so before anything is paywalled.

Why does Windows warn about the installer?

The installer is not code-signed yet, so Windows SmartScreen may show “Unknown publisher” or “Windows protected your PC.” That means Windows cannot verify the publisher; it is not proof that the file is malicious. Compare the installer against the matching .sha256 file on the release page, or build from source. Do not disable antivirus or click through a warning from a source you do not trust.

Is it faster than IDM?

We have not published a benchmark against IDM, so we do not claim to be faster. RapidFetch can use up to 32 HTTP range connections per file when the server supports them, which can improve throughput on some servers. Results depend on the server, CDN, your connection and disk. Servers that ignore range requests fall back to a single stream.

Why is it free? What is the catch?

The current core feature set is the product, not a trial. There is no paid tier, account or activation server to fund, and the code is MIT-licensed. If a paid tier is ever added, the free core stays and this page will say so before anything is paywalled.

Is RapidFetch on the Chrome Web Store?

Not yet. The Web Store listing is still pending, so use the extension ZIP for now: extract it, open chrome://extensions, enable Developer mode, click Load unpacked, and select the folder containing manifest.json. Chrome may show a developer-mode reminder while the unpacked extension is loaded; that is normal for a manual install and does not affect how RapidFetch works.

Does the Chrome extension work without the desktop app?

No. The extension is a companion: it captures downloads and media from Chrome and hands them to the RapidFetch desktop app on the same PC. Install the Windows app first, then the extension.

Which browsers are supported?

Chrome, Microsoft Edge, Brave, Vivaldi, Opera and other Chromium browsers with Manifest V3 support. The desktop app is for Windows 10 and 11, 64-bit.

Can it download YouTube, Facebook or other videos?

RapidFetch detects direct video, audio and HLS streams and can resolve supported pages through the optional yt-dlp engine, including Facebook reels and watch pages. Only download content you own or have permission to save, and respect each site’s terms.

Does RapidFetch collect my data?

No. There is no analytics, telemetry, advertising SDK or user account. Download history and settings stay in %APPDATA%\RapidFetch, and the extension only communicates with the desktop app on your computer. Read the privacy policy.

Why does the extension ask for access to all sites?

Downloadable media can be served from any domain, so the extension has to inspect the page and media responses on sites you visit to find download options. It does not inject ads, modify page content, or change your search engine or new-tab page.
